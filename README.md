# OPERIVA / AISI LAB — сайт на Next.js

Сайт лаборатории AISI LAB по ТЗ «Техническое задание на содержание сайта OPERIVA / AISI LAB».
Next.js 16 (App Router), TypeScript, без внешних UI-библиотек.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000 → перенаправит на /ru (или язык браузера)
npm run build && npm start
```

Требуется Node.js 20+.

## Настройки (.env.local, пример в .env.example)

| Переменная | Что делает |
|---|---|
| `NEXT_PUBLIC_CONTACT_EMAIL` | Подтверждённая почта. Пока пусто — почта на сайте не показывается. |
| `CONTACT_WEBHOOK_URL` | Куда отправлять обращения из формы (CRM, бот, почтовый сервис). Пока пусто — форма честно пишет «Отправка пока не подключена». |
| `NEXT_PUBLIC_CHAT_DELIVERY_ENABLED` | `true` — сообщения из чата уходят через тот же webhook. Пока `false` — чат помечен как демонстрация. |

## Структура

```
app/[locale]/            страницы (8 языков: ru en de es it fr ka pt)
  page.tsx               главная — 8 блоков ТЗ
  lab/                   Лаборатория: НАЛ, помощник, переводчик, цифровое бессмертие
  aisi-lab/              семейство AISI LAB (#hotels, #travel, #security)
  aisi-lab/hotels/       страница гостиничного продукта
  ai-workforce/  methodology/  governance/
  cases/  cases/tiflis/  company/  contact/  data-processing/
app/api/contact/         приём обращений → CONTACT_WEBHOOK_URL
content/                 все тексты: ru.ts (эталон), en.ts, de/es/it/fr/ka/pt.ts
lib/site.ts              реквизиты, почта, статусы и ориентировочные даты продуктов
lib/metrics.ts           показатели для блока «Проверки и ограничения» (пока пусто)
proxy.ts                 выбор языка при заходе на /
```

## Где что менять

- **Тексты** — `content/ru.ts` и `content/en.ts`.
- **Статус или срок продукта** — `lib/site.ts` → `readiness`. Значок и дата обновятся везде.
- **Показатели пилота** — `lib/metrics.ts`: каждая запись обязана иметь дату, среду (тестовая копия / пилотный отель), объём и источник.
- **Полный перевод языка** (de/es/it/fr/ka/pt) — сейчас переведены меню, формы, чат, статусы, ошибки и метаданные; тексты страниц показываются на английском с пометкой. Чтобы перевести язык целиком, сделайте полный словарь по образцу `en.ts`, подключите его в `content/index.ts` и выставьте `contentFallback[lang] = false`.

## Цвета и шрифты

Предложение, не утверждены: тёплый «бумажный» фон, графитовый текст, глубокий бирюзовый акцент; заголовки — системная антиква, текст — системный гротеск, статусы — моноширинный. Токены в начале `app/globals.css`, есть тёмная тема.
